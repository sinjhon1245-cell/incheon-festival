# 현장예약 — 1단계 DB 마이그레이션 적용 절차

- 대상: 운영 Supabase(`ynixjjqozkbzxjmishbe`) · SQL Editor(역할 `postgres`)
- 적용 파일: `supabase/migration-booth-live-mode.sql` (PR #59 브랜치 `claude/onsite-reservation`)
- 확인 파일: `supabase/check-booth-live-mode.sql` — 읽기만 하는 [1] 적용 전 · [2] 적용 후
- 되돌리기: `supabase/rollback-booth-live-mode.sql`
- 이 단계에서는 화면 배포 · PR 병합 · 기능 스위치 켜기를 하지 않습니다. 적용 뒤에도 스위치는 꺼져 있어 운영자 · 관람객 · 관리 화면이 지금과 같습니다.

## 순서
1. **때 고르기**: 운영자 입력이 뜸한 때(리허설 입력 중이 아닐 때)를 고릅니다. 23:00 자동 초기화와는 겹치지 않아도 되지만, 22:55~23:05 는 피합니다.
2. **[1] 적용 전 확인**: `check-booth-live-mode.sql` 의 [1] 칸만 붙여 넣고 Run 합니다.
   - 판정이 모두 `OK` 이거나 `기록` 인지 봅니다. `STOP` 이 하나라도 있으면 멈춥니다.
   - `기록` 줄(지문 20~25)은 캡처해 둡니다.
3. **migration 실행**: `migration-booth-live-mode.sql` **전체**를 붙여 넣고 Run 합니다(한 트랜잭션).
   - 마지막 결과가 `mode_rows 0 · enabled false · live_rows = [1] 의 booth_live 줄 수 · published_booths 84` 이면 적용된 것입니다.
4. **[2] 적용 후 확인**: [2] 칸만 붙여 넣고 Run 합니다.
   - 판정이 모두 `OK` 인지 봅니다.
   - 지문 20~23(부스 · 구역 · QR · PIN)이 [1] 과 **같은지** 봅니다.
   - 24(대기 현황)도 같아야 합니다. 다르면 25(마지막 입력 시각)가 [1] 보다 늦은지 봅니다 — 늦으면 그사이 운영자가 입력한 것이라 정상입니다.
5. **화면 확인(배포 없음)**: 지금 운영 중인 관람객 화면 · 운영자 화면이 이전과 같이 보이고 저장되는지 평소처럼 확인합니다. 스위치가 꺼져 있어 바뀐 것이 없어야 합니다.

## 멈추는 기준
| 언제 | 보이는 것 | 할 일 |
|---|---|---|
| [1] | `STOP` 한 줄이라도 | migration 을 실행하지 않습니다. 무엇이 다른지 알려 주세요 |
| [1] | 8번(잠금) 이 0 이 아님 | 1~2분 뒤 [1] 을 다시 실행합니다 |
| 실행 중 | `STOP: …` · `canceling statement due to lock timeout` · `permission denied` · `already exists` 등 오류 | 한 트랜잭션이라 **아무것도 반영되지 않습니다.** SQL Editor 에서 `rollback;` 을 한 번 실행합니다(트랜잭션이 없으면 경고만 나옴). 그다음 [1] 을 다시 실행해 3 · 4번이 `OK`(표 · 함수 없음)인지 확인하고, 오류 문구를 알려 주세요. 잠금 시간 초과면 잠시 뒤 다시 실행해도 됩니다 |
| [2] | `STOP` · 지문 20~23 이 다름 | 스위치는 이미 꺼져 있어 화면 영향은 없습니다. 더 바꾸지 말고 결과를 알려 주세요. 필요하면 아래 되돌리기를 실행합니다 |

## 되돌리기
1. `supabase/rollback-booth-live-mode.sql` **전체**를 붙여 넣고 Run 합니다(한 트랜잭션).
   - 예약 상태 줄만 지웁니다(이 단계에서는 0줄).
   - 함수 5개를 2026-11-03 정의로 되돌리고 md5 로 확인합니다.
   - 방식 표를 `private.booth_live_mode_backup` 에 복사한 뒤 새 표 · 함수 · 정책을 지웁니다.
2. [1] 을 다시 실행해 1~4번이 `OK` 인지 확인합니다(함수 md5 = 11-03 · 새 표 없음). 지문 20~23 이 처음 [1] 과 같아야 합니다.
3. 되돌리기 중 `STOP` 이 나오면 반영되지 않은 것입니다. `rollback;` 뒤 오류 문구를 알려 주세요.
