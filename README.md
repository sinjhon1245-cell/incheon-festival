# 제1회 인천 AI디지털 교육 페스티벌 — 랜딩 페이지

Claude Design 프로젝트의 `랜딩 - 클레이 3D.dc.html` 디자인을 실제로 동작하는
웹사이트로 구현한 것입니다. 공개 사이트와 관리자 사이트 두 벌이고,
행사 내용은 Supabase 에 저장됩니다.

빌드 도구가 없어 파일을 그대로 정적 호스팅에 올리면 됩니다.

## 파일 구성

```
index.html              공개 사이트 — 7개 탭 + 공통 푸터
admin.html              관리자 사이트 — 로그인 후 내용 편집

assets/config.js        ★ Supabase 주소·키 (직접 채우는 유일한 파일)
assets/data.js          Supabase 읽기 + 연결 실패 시 대체 처리
assets/fallback-data.js Supabase 연결 전에 보여 줄 기본 내용
assets/app.js           공개 사이트 동작 (디자인 CONFIG · 탭 라우터)
assets/styles.css       공개 사이트 스타일
assets/admin.js         관리자 동작 (로그인 · 목록 편집)
assets/admin.css        관리자 스타일

supabase/schema.sql     ★ 표 · 보안정책 · 초기 데이터 (한 번 실행)
dev-server.js           로컬 확인용 정적 서버 (배포에는 불필요)
design/                 원본 디자인 파일 (참고용)
```

## 탭 구조

상단 탭을 누르면 스크롤이 아니라 **페이지가 통째로 바뀝니다.**

| 탭 | 주소 | 내용 |
|---|---|---|
| 홈 | `#home` | 히어로 · 카운트다운 · 핵심 숫자 · 다른 탭 바로가기 |
| 프로그램 | `#program` | 다섯 갈래 프로그램 카드 |
| 시간표 | `#schedule` | 타임라인/표 전환, 갈래 필터 |
| 부스 배치도 | `#booth` | 구역 선택과 부스 목록 |
| 참여 안내 | `#apply` | 신청 없이 누구나 · 운영기관 부스 접수 |
| 오시는 길 | `#visit` | 약도 · 교통 · 주차 |
| FAQ | `#faq` | 자주 묻는 질문 |

주소에 해시가 들어가므로 `…/#booth` 처럼 **특정 탭을 바로 링크로 보낼 수 있고,**
브라우저 뒤로/앞으로 가기도 그대로 동작합니다. 탭을 바꾸면 화면이 맨 위로
올라가고, 브라우저 탭 제목도 함께 바뀝니다.

푸터는 모든 탭 아래에 공통으로 붙습니다. 문의처도 여기에 있습니다.

## 참여 방식

**사전신청 절차가 없습니다.** 누구나 당일 그냥 오시면 되는 행사라, 신청 폼으로
보내는 버튼을 두지 않고 안내를 전면에 세웠습니다.

- 상단 내비에는 신청 버튼이 없습니다 (탭만 있습니다)
- 히어로의 두 버튼은 폼이 아니라 **시간표**와 **부스 배치도**로 갑니다
- 히어로에 `✓ 신청 없이 누구나 오시면 됩니다` 안내를 따로 세웠습니다
- 참여 안내 탭 맨 위에 "신청 절차 없음" 안내를 파란 카드로 못 박았습니다
- FAQ의 "사전신청을 못 했는데…" 문항은 "신청을 하고 가야 하나요?"로 바꿨습니다

맨 아래에 있던 파란 CTA 띠와 상단 `10. 17. 토` 배지는 뺐습니다. CTA 띠에만
있던 문의처는 모든 탭에서 보이도록 푸터로 옮겼습니다.

부스를 **직접 운영하는 기관**의 신청(9. 7. ~ 9. 25.)은 별개라 그대로 남겼고,
참여자 신청과 헷갈리지 않도록 카드 안에 구분 문구를 넣었습니다.

탭을 늘리거나 줄이려면 `index.html` 의 `<nav id="nav">` 링크와 `[data-page]` 블록,
그리고 `app.js` 의 `PAGES` 배열을 같이 고치면 됩니다.

## Supabase 연결하기

연결하지 않아도 공개 사이트는 `fallback-data.js` 의 내용으로 정상 동작합니다.
관리자 기능을 쓰려면 아래 네 단계를 한 번만 해 주세요.
**1·2·4단계는 사용자 계정으로 하는 일이라 제가 대신 할 수 없습니다.**

### 1. 프로젝트 만들기

[supabase.com](https://supabase.com) 에서 무료 프로젝트를 만듭니다.
지역은 `Northeast Asia (Seoul)` 이 가장 빠릅니다.

### 2. 표 만들기

대시보드 왼쪽 **SQL Editor** → `supabase/schema.sql` 내용을 통째로
붙여넣고 **Run**. 표·보안정책·지금 사이트에 있는 예시 내용까지 한 번에
만들어집니다. 여러 번 실행해도 안전합니다.

### 3. 연결 정보 넣기

**Project Settings → Data API** 에서 두 값을 복사해
`assets/config.js` 에 붙여넣습니다.

```js
window.FESTIVAL_CONFIG = {
  supabaseUrl: 'https://xxxxx.supabase.co',
  supabaseAnonKey: 'eyJhbGciOi...'
};
```

> ⚠️ **anon public 키만** 넣으세요. `service_role` 키는 절대 안 됩니다.
> anon 키는 브라우저에 노출되도록 설계된 값이라 공개돼도 괜찮고, 실제
> 권한은 아래 보안 정책이 막습니다. `service_role` 은 그 정책을 전부
> 무시하는 마스터 키라, 넣는 순간 누구나 데이터를 지울 수 있게 됩니다.

### 4. 관리자 계정 만들기

**Authentication → Users → Add user** 에서 이메일과 비밀번호로 계정을
만듭니다. *Auto Confirm User* 를 켜 주세요.

회원가입 화면은 일부러 만들지 않았습니다. 아무나 가입해서 내용을 고치면
안 되니, 계정은 항상 대시보드에서만 추가합니다.

이제 `admin.html` 로 들어가 그 계정으로 로그인하면 됩니다.

## 관리자 사이트

`admin.html` — 공개 사이트 푸터의 "관리자" 링크로도 갈 수 있습니다.

| 항목 | 관리 내용 |
|---|---|
| 행사 설정 | 이름·개막 일시(카운트다운 기준)·장소·주소·문의처, 카운트다운/운영순서/주차표 표시 여부 |
| 프로그램 | 프로그램 탭 카드 |
| 시간표 | 오전·오후 순서, 갈래 |
| 부스 구역 | A·B·C·D 구역과 색 |
| 부스 | 부스 번호·이름·운영기관 |
| FAQ | 질문과 답변 |

목록은 기본으로 접혀 있고, 제목 줄을 누르면 그 줄만 펴집니다. 부스 16개를
훑을 때 차이가 큽니다. **↑↓ 로 순서를 바꾸고**, 고친 줄에는 "저장 안 됨"
표시가 뜹니다. 저장하지 않은 채 줄을 접거나 다른 탭으로 넘어가려 하면
막아 세웁니다. 저장하면 공개 사이트에 바로 반영됩니다.

관리자 화면 글꼴은 공개 사이트와 다릅니다. Gothic A1 은 제목용이라 14px
한글에서 흐려져서, 화면용으로 만들어진 Pretendard 를 씁니다. 못 받아오면
윈도우의 맑은 고딕으로 떨어집니다.

### 쓰기가 안 될 때

관리자에서 저장·삭제가 안 되면 화면에 이유가 뜹니다.

- **"… 대상이 0건이었습니다"** — 로그인이 풀렸을 가능성이 큽니다. 로그아웃 후
  다시 로그인해 보세요. Supabase 세션은 1시간마다 갱신되는데, 탭을 오래
  열어 두면 갱신이 실패하는 경우가 있습니다.
- 다시 로그인해도 같으면 `supabase/fix-policies.sql` 을 SQL Editor 에서
  실행하세요. RLS 를 끄지 않고 authenticated 쓰기 정책만 다시 만듭니다.
- 자세한 오류는 브라우저 개발자도구 콘솔에 `[admin]` 으로 남습니다.

DB 에 실제로 반영됐는지는 항상 **새로고침**으로 확인하세요. 화면에서 사라진
것과 데이터베이스에서 지워진 것은 다른 일입니다.

### 보안

관리자 페이지 주소를 남이 알아내도 **로그인 없이는 아무것도 바꿀 수 없습니다.**
막는 주체가 화면이 아니라 데이터베이스이기 때문입니다. `schema.sql` 의
RLS 정책이 모든 표에 이렇게 걸려 있습니다.

- 읽기(`select`) — 누구나. 공개 사이트가 anon 키로 읽어야 하니까요.
- 쓰기(`insert`/`update`/`delete`) — 로그인한 사용자만.

## 열어 보기

`index.html` 을 더블클릭하면 바로 열립니다. 외부에서 불러오는 것은 구글 폰트뿐이고
나머지는 모두 상대 경로라 파일로 열어도 그대로 동작합니다.

배포 환경과 똑같이 확인하고 싶다면 로컬 서버로 열어도 됩니다.


## 내용 고치기

**행사 내용(프로그램·시간표·부스·FAQ·설정)은 관리자 사이트에서 고칩니다.**
아래는 관리자에서 다루지 않는 디자인 값입니다.

**`assets/app.js` 의 `CONFIG`** — 원본 디자인의 컨트롤과 대응합니다.
`cornerRadius` 하나만 원본(8)과 다릅니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `colorway` | `하늘 블루` | 딥 네이비 · 시안 아쿠아 · 코발트 인디고 |
| `shadowDepth` | `기본` | 얕게 · 깊게 — 클레이 그림자 깊이 |
| `cornerRadius` | `18` | 8–40px. 원본은 8이었는데 각져 보여 올렸습니다 |
| `headlineScale` | `1.25` | 0.85–1.25 |
| `density` | `기본` | 여유 · 조밀 — 섹션 사이 여백 |
| `bodyFont` | `고딕 단일` | `고운돋움 혼용` 으로 바꾸면 본문이 고운돋움이 됩니다 |
| `showOpsTrack` | `false` | `true` 로 바꾸면 세팅·점심·철수 등 운영 순서가 시간표에 함께 나옵니다 |
| `showParkingTable` | `false` | `true` 로 바꾸면 주차 안내 표가 나옵니다 |
| `boothNumbers` | `번호 전체` | `범위만` 으로 바꾸면 구역 카드의 번호 칩이 숨겨집니다 |
| `boothUrl` | `#apply` | **부스 운영 신청 안내 문서 주소.** 참여자는 신청이 없어 따로 링크가 없습니다 |

`assets/fallback-data.js` 는 Supabase 연결 전에만 쓰입니다. 연결한 뒤로는
관리자에서 고친 내용이 우선하므로 이 파일은 건드릴 일이 없습니다.

## 아직 채워야 할 것

원본 디자인에 예시로 들어 있던 값이라 실제 정보로 교체해야 합니다.

- 부스 운영 신청 안내 문서 링크 (`CONFIG.boothUrl`)
- 전화번호·주소 — **관리자 → 행사 설정**에서 고칩니다
  (참여 안내 탭의 운영 신청 카드 전화번호만 `index.html` 에 있습니다)
- 지도 이미지 — `#mapcard` 안의 `.mapslot` 자리를 `<img src="assets/map.png" alt="행사장 약도">` 로 교체
- 공유용 대표 이미지 (`og:image` 메타 태그가 아직 없습니다)
- 푸터의 "검토용 예시 데이터입니다" 문구 — 확정 후 삭제

## 구현 노트

원본 디자인과 다르게 처리한 부분입니다.

- **제목 크기에 `clamp()` 적용.** 원본은 고정 픽셀이라 좁은 화면에서 히어로
  제목이 넘쳤습니다. 데스크톱에서는 원본과 같은 크기입니다.
- **FAQ 는 `<details name="faq">`** 로 구현했습니다. 자바스크립트 없이도 열고
  닫히며, 하나를 열면 다른 하나가 닫히는 동작도 브라우저가 처리합니다.
- **시간표와 부스 목록만 자바스크립트로 그립니다.** 필터가 필요한 두 곳이라
  데이터를 한 군데에 두는 편이 관리하기 쉽습니다. 나머지는 모두 HTML 에
  들어 있어 검색엔진과 화면 낭독기에서 그대로 읽힙니다.
- **탭은 해시 라우팅**입니다. 페이지를 새로 받아오지 않아 전환이 즉시 일어나고,
  링크 공유와 뒤로가기는 그대로 동작합니다. 자바스크립트가 꺼져 있으면
  `has-router` 클래스가 붙지 않아 7개 페이지가 예전처럼 한 장으로 이어집니다.
- **탭을 바꾸면 새 페이지 제목으로 초점을 옮깁니다.** 키보드와 화면 낭독기
  사용자가 바뀐 위치를 알 수 있도록 하는 처리이고, 현재 탭에는 `aria-current`
  를 붙였습니다.
- **접근성 보강.** 본문 건너뛰기 링크, 필터·구역 버튼의 `aria-pressed`,
  키보드 포커스 표시, `prefers-reduced-motion` 대응을 추가했습니다.
- **인쇄 스타일**을 넣어 종이로 뽑으면 그림자 없이 FAQ 답변까지 모두 펼쳐집니다.
- **Supabase 가 죽어도 사이트는 안 죽습니다.** 연결이 없거나 실패하면
  `fallback-data.js` 로 그냥 보여 줍니다. 행사 안내 페이지가 네트워크
  문제로 백지가 되면 안 되니까요. 지금 무엇으로 그렸는지는 개발자 도구에서
  `<html data-source="supabase|local">` 로 확인할 수 있습니다.
- **프로그램 카드와 FAQ 도 이제 자바스크립트로 그립니다.** 관리자에서 고칠 수
  있게 하려면 필요한 변경이지만, 그만큼 검색엔진에는 덜 읽힙니다. 학교 홍보
  채널로 알리는 사이트라 이 교환은 괜찮다고 봤습니다.

## UI를 다듬으면서 바꾼 것

원본이 진하고 단순해 보이던 이유를 셋으로 보고 손봤습니다.

- **모서리 8 → 18px.** 클레이 느낌인데 각이 져 있어 곡률을 올렸습니다.
- **그림자 한 겹 → 두 겹 + 실선.** 굵은 그림자 하나 대신, 윤곽을 잡는 가까운
  겹과 띄우는 먼 겹으로 나눴습니다. 흰 카드가 밝은 배경에 묻히지 않게
  머리카락 굵기 실선(`--hair`)을 둘렀고, 아랫단 턱은 4px → 2.5px로 얇게.
- **글자 굵기 900 → 700·800.** 본문 라벨까지 900이라 전체가 소리치는 느낌이었습니다.
  제목은 800, 라벨과 메타는 600·700으로 낮추고 자간을 조였습니다.

그 밖에 버튼은 단색에 검은 띠를 두르는 대신 위쪽 하이라이트와 얇은 턱으로
솟아오르게 했습니다. 시간표 항목에는 왼쪽에 갈래 색 띠를 넣어 색만 보고도 구분되게 했습니다.

**한글 줄바꿈**도 함께 잡았습니다. `word-break: keep-all` 이 없으면 한글이 단어
중간에서 잘려서, 좁은 화면일수록 읽기가 나빠집니다.
